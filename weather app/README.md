# Skyline — Weather Finder

Modern weather app built with React, Vite, Tailwind CSS, and the OpenWeatherMap API.

## Setup

1. Copy `.env.example` to `.env`
2. Add a free API key from [OpenWeatherMap](https://openweathermap.org/api):

```
VITE_OPENWEATHER_API_KEY=your_key_here
```

3. Restart the dev server after changing `.env`

```bash
npm install
npm run dev
```
